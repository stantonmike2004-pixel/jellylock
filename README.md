# jellylock

[![Install with Tampermonkey](https://img.shields.io/badge/INSTALL-JELLYLOCK-purple?style=for-the-badge&logo=tampermonkey)](https://raw.githubusercontent.com/stantonmike2004-pixel/jellylock/refs/heads/main/JellyLock.user.js)

🔒 **JellyLock**: Stealth playback lock for Jellyfin Web.

✨ **Features:**
- Toggle lock with `Ctrl+Shift+F8`
- Hides video OSD, player controls, & mouse cursor
- Blocks accidental clicks via transparent overlay
- Disables Space, K, Arrow keys, & media controls while locked

Zero-UI, zero dependencies, pure vanilla JS.
