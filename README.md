# jellylock
🔒JellyLock Stealth playback lock for Jellyfin Web.  ✨ Features:  Toggle lock with Ctrl+Shift+F8  Hides video OSD, player controls, &amp; mouse cursor - Blocks accidental clicks via transparent overlay - Disables Space, K, Arrow keys, &amp; media controls while locked  Zero-UI, zero dependencies, pure vanilla JS.
